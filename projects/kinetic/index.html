Kinetic

A customizable code editor with a custom-drawn interface, a Rust backend, and a C++ frontend. Built for macOS first.

Install Kinetic ↓Source ↗
Early previewApple Silicon · macOS 15+Rust / C++Apache-2.0

In the editor

Multiple tabs, a project file tree, find and replace, project search, a command palette, configurable themes and indentation, and native Rust/C++ plugins.

C/C++ Support connects to clangd for completion, diagnostics, and Go to Definition, with clang-format for formatting. Missing language tools can be installed on demand; the full LLVM toolchain is not bundled.

Install

Apple Silicon · macOS 15+ · Kinetic 0.36.0

Builds verified source locally and installs Kinetic.app with its CLI. Requires Xcode Command Line Tools, CMake 3.28+, Cargo, and Python 3. No LLVM or language servers are bundled or downloaded.

curl -fsSL --proto '=https' --tlsv1.2 https://gideoncox.com/downloads/kinetic-install.sh | sh

Read the installer before running it. The source archive is pinned by commit and SHA-256. Existing apps or Homebrew links require confirmation and are retained as backups; settings and plugins stay untouched. Build dependencies are never installed automatically.

Launch the installed app:

open "$HOME/Applications/Kinetic.app"

Installs the CLI at ~/.local/bin/kinetic. Add that directory to PATH if needed. Re-run the installer to build the version currently offered here. Use sh -s -- --work-dir /path/to/scratch instead of sh to choose a build drive.

The app is locally signed, not Apple-notarized. The installer does not disable Gatekeeper or remove quarantine attributes.

Still in development

Kinetic is an early functional preview, not a finished daily-driver editor. Linux and Intel Mac support are planned, but not available yet. The current app is macOS-only.
